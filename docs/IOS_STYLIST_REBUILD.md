## 用户要求及实现边界

- 新模块集中在 `AICloset/Sources/Module2.0/Stylist/`，Core/Networking/UI/Resources/Tests 分层；宿主登录、V3 网络、导航兼容、旋转策略和键盘管理只在 Integration 适配；AppDelegate/TabBar 仅调用模块边界方法。
- 原 Agent 入口、首页历史/卡片及首次引导接入新模块，31 个旧聊天 UI/会话运行源文件退出 App 编译；按 iOS 仓库迁移要求保留历史源码。其他模块仍在使用的兼容模型/工具保留。旧聊天和旧付费动作不自动迁移或重放，不改旧数据库。
- 自行封装导航、面板、按钮、选择器、开关、日历、消息与图片卡，沿用当前六角色素材、男女主题及系统配色；使用系统输入、滚动、照片权限/选择等底层能力。
- 全面屏与非全面屏按安全区域和键盘布局；短屏内容滚动，设置/手记保存固定在底部。单品详情固定一屏，横屏收起整套区以保留单品操作。
- 首页、SSE 对话、历史、四步设置、偏好手记、城市天气、体验签到、上传预览、数字人、试穿报价确认/任务、搭配透明组合图与单品详情均已接入原生页面。请求 ID/版本/账号和角色快照保持隔离；未知收费结果只读任务，不自动重试扣费。
- 用户提供的调试身份仅存于模拟器私密配置，不写入源码、资源、构建参数、日志或此文档；正常 App 使用宿主账号。调试 scheme 为 `Stylist`。

完整实现说明、运行方法、限制及合成截图见 [iOS 验收文档](../../../ios/aicloset-IOS/docs/STYLIST_REBUILD.md)；结构见 [模块 README](../../../ios/aicloset-IOS/AICloset/Sources/Module2.0/Stylist/README.md)。
