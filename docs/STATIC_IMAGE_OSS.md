# 前端图片 OSS 外置

2026-11-10，当前规则：仅外置公开图片，不迁移 JS、CSS、字体、Worker、WASM、ONNX、接口或业务数据。用户本次明确授权测试账号完成性别设置并获取新登录 token；token 仅在上传进程内存使用，未写文件、日志或 Git。本文不记录账号。

## 加载与发布

- `stylist/static/image-oss-manifest.json` 维护 212 个图片路径、35 个原内嵌图片及 SHA256，去重为 241 个 OSS 对象。235 个对象本次上传，6 张埋点说明图沿用此前已存在的 OSS 链接，不重复上传。
- 本地源图片保留。`ImageStaticFiles` 将原 `/static/...` 图片入口以 307 转向 HTTPS OSS；保留旧引用与动态拼图／CSS 图集引用，响应不缓存旧的跳转目标。JS、CSS、SVG、Worker 和模型继续同源提供。
- 三个独立参考 HTML 中的 PNG／JPEG／WebP Base64 图片已替换为 OSS 链接，页面内容、脚本与图片视觉不改。原页面可从 Git 或本次本地备份恢复。
- WebP 在上传前无损解码为 PNG，清单分别记录本地源文件和上传对象的哈希，不将两种编码的二进制哈希混为一谈。
- `.dockerignore` 逐路径排除已外置图片；`release_files`／`prepare_release_tree` 依据同一清单省略图片，并核对本地源文件大小与哈希。源图变化而映射未更新时拒绝打包，避免静默发布旧图片。
- 私密截图目录、用户图片及凭证不上传。当前所有非私密 PNG／JPEG／WebP 都有映射；约27 KB的SVG仍保留本地，现有上传接口不接受SVG，不伪装后缀或改变图标画法。
- 12张发布器生成的合成演示图也有映射；未提交的引导体验页面不因为图片迁移而获得提交／发布授权，正式交付从隔离清单取源码。

## 维护与验证

```bash
.venv/bin/python scripts/manage_image_assets.py
# 更新公开清单后同步Docker排除项：
.venv/bin/python scripts/manage_image_assets.py --sync-dockerignore
# 按需重新下载核对全部公开对象，不需要账号或token：
.venv/bin/python scripts/manage_image_assets.py --verify-remote
```

新增或修改图片时，先使用本次有效token上传PNG／JPEG并核对远程哈希，再更新清单；WebP先无损转PNG。不要复用旧token，不将token写入清单或命令行参数。未列入清单的新图片不会被自动删除；维护检查会指出遗漏。

235个本次上传对象均已下载核对远程SHA256与CORS。现有6张埋点说明图的哈希也已核对，原OSS响应无CORS头；它们仅供报告`img`展示，清单标为不要求Canvas跨域，不冒充已通过Canvas验收。业务图片PNG／JPG／WebP的浏览器Canvas读像素验证通过。
