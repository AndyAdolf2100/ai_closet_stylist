# 我们的手记：长记忆

日期：2026-10-29。对应 AGENTS.md PRD-12；本地工作区已实现，未提交或远端部署。

## 使用

设置 → 我们的手记：添加、编辑正文和分类、删除纸页、暂停／恢复参考，点击「收好这几页」才提交，关闭或取消不保存草稿。最多30条，每条240字；三类为穿衣习惯、日常片段、相处约定。手机全屏、桌面居中，沿用男女角色主题和当前助理昵称，提示复用 message。

聊天可以说「我平时不穿高跟鞋，更喜欢平底鞋，这件事一定要记住」。也支持「以后都记着」「把这个记下来」「别忘了」「保存到长记忆」等明确意图。自然语言由计划阶段识别；上文指代只取用户原话，歧义需澄清。普通陈述、否定、举例、转述和询问不视为保存授权。明确冒号命令「记住：内容」可直接保存，不调用模型。系统持久化成功后才交付保存回执；同内容去重。

## 存储和生效边界

- `stylist_memory_books` 是本项目独立表，当前本地位于 `stylist_local`。不读写或迁移旧 Go 服务记忆。
- `GET/PUT /stylist-api/memories` 都经上游身份认证；客户端不能指定 owner。整本提交携带 revision，旧窗口冲突返回409，不静默覆盖。
- 每次新请求由服务端读取账号记忆，放入 LangGraph 请求检查点快照；进行中的请求、等待确认和失败恢复沿用原快照。
- 聊天保存与会话结果在同一事务提交；满额或写入失败整体回滚，不返回成功。旧成功请求重放不重新插入已删除条目。
- 修改、删除和停用从下一次新请求生效。删除不清除历史聊天、任务快照，也不代表彻底擦除所有历史副本。
- 穿衣习惯由模型引用原话生成 `memory_changes`，程序只接受受限字段和已有手记证据。它们只合并到本轮有效要求，不持久化进会话任务；当前显式要求和已明确任务限制优先。为他人搭配、纯天气、闲聊或拒绝本人偏好时不应用这些选款默认条件。
- 记忆是资料，不能授权收费、读取其他账号、启用系统衣橱或改变工具权限。库存、天气与局部冻结仍经原流程校验。
