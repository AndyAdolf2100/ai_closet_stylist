### 登录与引导

品牌爱搭衣橱、统一称助理；历史入口为聊过的日常。正式登录与引导复用App同源页面，前两步不可跳过，称呼、用户性别和具体角色必填；助理昵称留空或纯空格默认衣衣。第三、四步可选，最后入口为和我直接聊一聊。设置编辑页仍独立校验。登录及引导保留对话正文、移除署名并清理顶部margin。

首页与聊天共享城市；点击才定位、确认后保存，失败可手选。引导第五步定位可选、弹窗居中。首页无城市显示六人格穿搭提示，选城且登录后显示单行城市、天气、温度；十分钟隔离缓存，失败如实提示，不自动发对话。真实GPS另验。

### 穿搭偏好与个人页

## 2026-11-04：账号头像、试穿形象与初次见面

- **账号头像**：爱搭衣橱“我的”页点击头像即可选图，更换当前账号头像；选图后居中裁为512×512 JPEG并保存。允许10MB以内JPG／PNG／WebP原图，保存成功立即更新，失败保留旧头像并用message提示；取消不写入，提交时禁用重复选择，切换账号忽略旧响应。头像上不显示“更换”文字覆层，保留无障碍名称及点击能力。与助理头像、试穿形象分别管理。
- **我的试穿形象**：原“我的数字分身”改名，卡片采用左图右文。图片标题右侧小眼睛切换显示／隐藏；隐藏时用柔和水彩匿名人物剪影替代真人图，不再用模糊人脸或图片下的独立按钮。
- **剪影性别**：按已保存的用户本人`user_gender`选择男／女素材，与`assistant_persona`及助理性别无关；未知性别使用中性背景，不从照片推断。修改用户设置即时更新，换号清理旧选择。
- **隐藏偏好**：按账号记住当前浏览器选择，刷新保留、换号分别读取；没有已创建形象时不显示开关。只是个人页的显示遮挡，不修改原图、不删除形象、不影响试穿；不是图片访问权限，也不自动隐藏其他试穿结果。无需假设用户性别。
- **登录与onboarding**：未登录仍可浏览首页，需要账号的操作进入独立登录页；复用现有手机号验证码校验，没有新增短信发送／独立注册／第三方授权。登录后已保存`agent_name`为空或没有资料时进入引导，必填称呼、用户性别及具体角色；助理昵称可留空，空值或纯空格默认「衣衣」，非空昵称去除首尾空白，成功保存后进入App；失败保留草稿。

## 1. 产品目标与范围

爱搭衣橱将个人衣橱、穿搭记录和日常陪伴组织在一个应用中。用户既可以直接管理衣物，也可以向已有的穿搭 Agent 描述场景，在本人衣橱和有效天气信息的基础上获得建议。

主要路径：进入首页 → 登录已有衣橱账号 → 查看造型或灵感 → 与助理交流／添加衣物 → 按需选择试穿形象及确认费用 → 保存与回看日常记录。

本轮要求：

- 先整理整个 App 的需求，以现有 H5 为基础制作爱搭衣橱风格方案。
- 保留首页、衣橱、我的三栏和创建入口，以及现有 Agent 的页面、接口和业务行为。
- 保留女版、男版、系统三种配色；配色独立于助理人格、用户性别和搭配对象。
- 本轮只修改本仓库的 H5 外壳；不修改 iOS，不迁移旧业务数据，不新增真实收费流程。
- 原 iOS 风格对照版保留，方便比较。后续原生迁移需独立安排，不将 H5 完成视为原生完成。

## 4. 爱搭衣橱视觉方案

### 4.1 统一风格

采用纸面感背景、克制边线、宋体感标题与系统正文字体。图片以真实衣物／造型为主，陪伴形象只出现在有明确身份语义的位置。导航、创建和管理入口使用同一套线性 SVG，避免继续混用彩色玻璃球、强光晕和工具型图标。

首页以「今天，穿得像自己」和主动聊天入口建立陪伴感，下方保留造型册、灵感和活动分类。衣橱强调“已有衣物”；我的页面以身份、关于我的小事、记录与管理组织信息。新增静态文案不是模型回答，不表达未验证天气、库存或个性化事实。

### 4.2 三种配色必须保留

| 配色 | 页面／纸面 | 主文字／次级文字 | 强调与主按钮 |
| --- | --- | --- | --- |
| 女版奶油绿 | #FBF7F2／#FFFDFA | #42483C／#8B8175 | #63775B；白字主按钮 |
| 男版雾蓝 | #F4F6F8／#FDFEFD | #293A4C／#73818E | #3C5B79；白字主按钮 |
| 黄色系统色 | #FFFFFF／#FFFFFF | #302F29／#858174 | #FCDA4F主按钮、深色字；强调文字#8A6915 |

三套共享结构、字号、圆角和操作区域；切换仅改变配色。黄色系统色不把页面和对话背景涂黄。女／男是已有配色名称，不据此推断用户性别或更换助理。爱搭衣橱版顶部提供三个至少44px的选择按钮，显示选中状态并支持键盘操作。

当前配色控件是外壳视觉预览，本地保存，不写回 companion-profile。进入 Agent 后仍由其已有、按账号保存的助理及配色设置控制；后续若要求外壳与 Agent 双向同步，应另行统一持久化规则，不偷偷覆盖用户设置。

### 4.3 资源与组件

优先复用现有公开设计资源和爱搭衣橱角色头像；不把用户照片复制进静态包，不拉伸人物。新增线性图标使用 SVG 路径并跟随主题色。造型册和灵感仍使用各自数据图片，禁止用角色插画替代真实搭配。

## 5. 关键交互与状态

- **未登录**：主界面和配色可浏览；账号列表提示连接衣橱，不伪装成没有库存。登录入口为独立登录页，验证码来自现有账号服务。
- **加载／失败／空数据**：区分加载中、成功但无记录、身份过期和服务不可用。失败提供重试，不将失败渲染成空衣橱。
- **进入 Agent**：点击明确入口才进入；同源独立页面保留会话。外壳不自动发送请求，不因换色调用模型。
- **创建**：打开面板，选择动作；关闭恢复原页面和焦点。短屏内容独立滚动，最后一项不被底部导航挡住。
- **图片详情**：展示当前选中图和已有说明；加载失败显示缺图状态。完整业务结果操作尚未接入时不伪造可编辑状态。
- **账号切换**：当前内容清空、旧请求作废；助理昵称／头像重新读取。配色与试穿形象隐藏选择按各自规则保留，照片不保存到浏览器存储。
- **待接入入口**：明确说明尚未接入，不显示假的成功、账单、积分或任务进度。
