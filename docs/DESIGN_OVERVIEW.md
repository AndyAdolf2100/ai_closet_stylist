# 从零到当前：设计手记 HTML

入口：<http://127.0.0.1:8466/static/design-overview.html>。
源码：[`stylist/static/design-overview.html`](../stylist/static/design-overview.html)。

此页沿用衣间的奶油／鼠尾草绿与雾蓝／海军蓝主题，汇总产品定位、设计想法、当前需求及视觉演进。
它是独立的设计评审页，前端业务页面与账号设置不受其预览操作影响。

## 收录范围

- 产品起点、用户旅程、2026-10-27至10-29的阶段演进。
- 当前12章需求及可展开的完整规则，包含已实现能力和待验边界。
- 本轮iPhone输入字号修复、离线部署和本设计总览需求。
- 男女原创角色、正常比例和Q版、全身设定、立绘与当前眨眼动画。
- 8种天气氛围、4种预警等级样式、16类装饰性提醒动作。
- 称呼与人格、12张星宫、偏好、来信、体验签到和显式长期手记。
- 原项目47张公开图片，含当前素材、设定、历史探索与生成参考；支持筛选、搜索、放大和下载。
- 服务／MCP／模型／数据库边界、部署状态、原有预览入口。
- 需求变更记录、Git迭代轨迹，以及尚属提案的年度构想。

## 展示边界

图片来源仅为 `stylist/static/assets/` 中既有原创素材，不读取用户衣橱、照片、凭证或会话。
天气和预警均明确标为样式示例。星宫属于娱乐装饰，不提供真实运势或性格推断。
年度清单、提醒、小游戏及小屋等仅为构想，不能根据本页认定已实现。
页面只请求静态资源；主题、称呼和星宫预览不调用API、模型或写入浏览器持久存储。

HTML中的 `overview-data` 是本次整理快照。新增需求、素材或迭代时应同步更新该快照及数量，
保留历史记录当时的状态，以当前需求规则说明现状。静态网页需要同一服务下现有CSS、JS和图片，
不是把47张原图全部编码嵌入的离线单文件；运行本地服务后访问上述地址。

## 本地验证

独立无账号的Chromium测试检查1440px、844px、390px及320px布局，没有横向溢出或JS运行异常。
检查需求章节、图集、天气／灾害／星宫数量，以及筛选、搜索、图片放大关闭、主题切换、暂停、星宫取消和称呼纯文本渲染。
确认无localStorage／sessionStorage写入，预览只请求静态资源。
检查桌面、手机首屏、动画、天气及图集截图；记录保存在被忽略的 `var/design-overview-check/`。
这些是桌面浏览器及视口模拟证据，不是iPhone Safari软键盘或真实天气／账号业务验收。

本页随下一次正常构建自动进入发布包；没有据此更新远端服务器或重新打包之前的iPhone修复包。
