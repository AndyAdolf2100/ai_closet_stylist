# 气象预警、天气背景与省市联动

更新：2026-10-27。适用新版8466。

## 已实现

- 省份→城市两级联动，固定文件`stylist/static/china-cities.json`，包含34个省级选项、369个城市及同级选项。不显示区县层级。直辖市第二级使用北京市等本身；自治州、地区、盟保留为同级选择；省直管城市保留。香港、澳门各为单一城市选项，台湾省列9个城市。列表存在不代表天气服务已经覆盖，最终仍经业务城市目录校验。
- 列表来源：[modood/Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China/blob/master/dist/pc.json)，本地快照并作上述产品层级调整；原许可证见`CHINA_CITY_DATA_LICENSE`。台湾城市参考[地方政府介绍](https://www.president.gov.tw/Page/106)，不把县混入城市。离线选择无需访问在线地名服务，新增城市需更新文件。
- 天气卡装饰背景按实际返回的天气文本映射：晴/阴云/雨雷/雪冰/雾霾沙尘/风。六张原创AI自然氛围图片在`stylist/static/assets/weather-*-v1.png`，不是当地实时照片。白色渐变遮罩保证文字可读；背景不改变实际天气数据。
- 置顶预警栏在主布局中、聊天滚动区外，不会被聊天内容推走。支持红橙黄蓝，等级文字与颜色同时呈现。保留灾害类型、影响区域、发布机构、时间与原始防护正文；多条按等级和发布时间排序，正文可展开，不提供一键永久隐藏严重预警。
- 原创衣衣灾害动作图为`yiyi-hazards-v1.png`，4×4共16类：暴雨、雪、雾、风、雷电、高温、寒潮、沙尘、结冰、冰雹、干旱、火险、台风、龙卷风、洪水及其他。未知灾害用通用警示，不生成虚构气象信息。
- 切换确认城市后更新该城市预警；页面可见时每两分钟查询，切回标签页也刷新。历史对话中的天气不会替换当前城市预警栏。未登录不查预警。
- 独立样式页：`/static/weather-preview.html`。所有样例均明确标记“演示、非真实预警”，不进入真实城市预警栏。

## 当前真实数据限制

现有Go业务天气接口没有正式预警字段，当前配置也没有已验证的预警数据源。墨迹独立预警权限尚未确认，原供应商域名的HTTPS证书问题仍未解决；本次不绕过证书、不向浏览器暴露密钥、不抓取声明禁止未经授权使用的气象网站数据来冒充接口。

因此，当前真实页面显示“官方预警信息暂未接通……这不代表没有预警”。不根据小雨或大风推导红黄色预警。置顶呈现、筛选和角色图片已实现，**真实红黄色预警接入仍待可用且有授权的数据源**。

## 数据源契约

`STYLIST_ALERTS_URL`指向受信任、已获授权的HTTPS预警适配服务；可选`STYLIST_ALERTS_KEY`仅用于该服务，不转发用户Bearer。未配置、超时、数据过期或格式异常均为unavailable，不是“无预警”。这是标准化适配契约，不是声称墨迹原始接口天然使用同名字段。

查询：GET，参数`city_name`和`province_name`为业务目录确认后的名称。响应：

```json
{
  "observed_at": "2026-10-27T13:00:00+08:00",
  "complete": true,
  "alerts": [{
    "id": "official-alert-id",
    "level": "red",
    "event": "暴雨",
    "title": "由发布机构提供的真实标题",
    "text": "原始灾害信息与防护内容",
    "sender": "实际发布机构",
    "city_name": "北京市",
    "province_name": "北京市",
    "area": "实际影响区域",
    "issued_at": "2026-10-27T12:00:00+08:00",
    "expires_at": "2026-10-27T15:00:00+08:00",
    "status": "active",
    "source_url": "https://authorized-source.example/warning"
  }]
}
```

示例只说明格式，不代表上述城市当时有预警。`observed_at`是数据源核对当前预警状态的时间，需在15分钟内；不能把旧记录重新包装成新数据。每条需明确active/cancelled/expired；相同id最新记录优先，解除及过期不展示。城市/省份不匹配或部分无效记录会标partial，不能当作覆盖完整。只有新鲜、格式正确且complete=true的空列表才表示本次源未返回生效预警。尚未接入精准区县匹配，市内局地预警保留原影响区域，用户需自行核对适用范围。

新接口：`POST /api/weather/alerts`，请求`{location:{city_name,province_name}}`，需有效登录。返回ok/partial/unavailable和规范预警列表；与普通weather-alerts穿搭规则完全分开。模型可参考原始预警内容，但不能生成预警等级或解除状态。

## 验证

自动化覆盖：预警等级排序、解除记录覆盖、过期过滤、跨城市数据不冒充本地、缺失和过期数据不冒充无预警、灾害图映射、未登录保护、省市静态层级。上游没有真实可用预警源，模拟测试不算实时预警验收。

本轮58项pytest通过，Ruff及两个JS文件语法检查通过。浏览器实际确认：原三亚天气正常加载雨景背景；省份从海南切换浙江后城市清空，列表仅显示杭州等11市，取消不改动原三亚选择；六类背景与16类灾害图片在明确标注的演示页中检查。真实预警接口返回unavailable提示，并未显示模拟红黄色预警。
