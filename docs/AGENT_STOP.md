## 接口与边界

`POST /stylist-api/chat/stop`，沿用当前Bearer身份，JSON复用当前发送的完整ChatRequest。仅匹配相同凭证与请求，不按用户提供的owner字段操作。返回`stop_requested`为当前进程已发出取消，`not_running`为该进程未找到活动任务，不能当作全球完成状态。普通断线不调用该入口。

停止为尽力取消，已执行的模型调用／已提交的历史不能撤销；不触发图片任务或退款。停止标记仅内存10分钟、最多2048项，不跨重启／Pod持久化，多副本需请求路由到执行实例才能取消；本次未实现分布式广播。前端停止响应不明时明确提示未确认，保留输入。

新一轮发送使用新request_id；被停止的旧请求不自动重试。取消中禁用按钮，积分检查迟到后不继续发对话或弹不足卡；已有部分正文保留为未完成预览，不写成正式结果。
