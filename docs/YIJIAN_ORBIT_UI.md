## 当前实现

| 页面 | 新版呈现 | 功能边界 |
| --- | --- | --- |
| 首页 | 全身角色、拱窗光影、悬浮快捷入口、对话面板 | 复用聊天、历史、称呼设置、签到 |
| 造型册／灵感 | 通透卡片、日期与穿搭相片 | 原列表、分页、图片与详情 |
| 衣橱 | 场景标题、玻璃操作栏、收藏分区 | 原统计、单品、衣橱等入口 |
| 个人中心 | 身份卡、独立角色小笺、记忆星笺、功能网格 | 原资料、积分、记忆、记录及设置 |
| 创建面板／详情 | 统一光影、边框、标题、按钮 | 原动作、关闭、返回与焦点处理 |
| Agent | 仅外壳返回栏统一样式 | iframe 内原 UI、账号设置及业务不变 |

奶油绿、雾蓝、系统黄三色保留。切换只改变外壳配色，不改变所选角色或账号设置。角色沿用共同元数据的正面裁切与比例校准，不拉伸三视图。支持减少动态效果；窄屏场景设最小高度并允许页面滚动，避免对话面板遮住签到入口。

实现主要位于 `stylist/static/closet-app/orbit.js`、`orbit.css`；bootstrap 识别 edition，复用既有 yijian 呈现层和 app 操作。所有新增样式限于 orbit。业务代码、后端接口未因本提案变更。

## 2026-11-03 配色修订

用户要求 Orbit 也恢复已提交主题色，与选定的 Onboarding 一致。男版背景 #f4f6f8、主色 #3c5b79；女版背景 #fcf8f5、主色 #64775d；系统白底、按钮 #fcda4f、深色字 #302b1f。主题值来自已提交 Agent 的 style.css 与 system-colors.css。

此修订替代上文通透混色呈现：首页、衣橱、个人中心、创建面板、详情与导航改为不透明纸面及轻边框，去掉彩色光晕、混色渐变与移动光束；背景衣橱插画减淡去色。角色、照片、场景结构、三色切换及业务交互保留。更新截图仍在 var/orbit-preview；使用模拟数据，不代表真实账号验收。

## 横向边界修订

2026-11-03：用户要求左右不要溢出。页面根层限制横向溢出与横向回弹，内容容器约束横向边界；首页分类改为等分自适应，取消局部横向滚动。长账号名、角色文案和详情标题允许断行，保留纵向滚动、原布局宽度及浏览器缩放。模拟检查320／375／393／844px基础页面未发现已有文档超宽，此修订同时加固动态文本与触屏横向边界；真机Safari回弹需实机核对。
