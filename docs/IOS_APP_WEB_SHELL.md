日期：2026-11-03。用户要求参考当前 iOS 补齐前端交互，尽可能 1:1，现有 Agent 保留。

## 范围与入口

本轮按「首页／衣橱／我的及创建面板」理解并开始实现；范围澄清尚未收到答复。这是第一阶段外壳，不是整个 iOS App 的完整迁移。

- 新入口 `/app/`，开发预览 `http://127.0.0.1:8478/app/`。
- 原 `/`、`/mobile/` 和 Agent 静态文件、接口、模型流程不变。
- `stylist/static/closet-app/` 独立 HTML/CSS/JS 和资源。Agent 同源 iframe 首次进入时加载，往返保留页面与对话状态；跳转只触发现有按钮，不自动发消息或保存设置。
- `stylist/closet_app.py` 固定页面读取白名单，无任意代理地址，无新增上传、生成、收费或数据库写入。请求沿用现有上游地址和当前登录凭证；不新增凭证文件。

## 第二轮还原度核对（2026-11-03）

结论：第一阶段存在明显的有数据排版差异，之前的空态和通用交互检查不能代表视觉接近 1:1。本轮根据当前原生源码核对并修复以下项，没有给出缺乏依据的整体百分比。

| 区域 | 查出的差异 | 本轮处理 |
| --- | --- | --- |
| 首页右上角 | Web 使用彩色球，原生是「聊天记录」渐变胶囊 | 替换为原生文案、字号、渐变与胶囊；窄屏分类栏可横向滚动 |
| 造型册多单品 | Web 大图下方横向单品条，与原生双列结构不同 | 改为左列单品／右侧试衣效果；复用3份光晕；舞台388/367、单品列107/367、列距5px、上8px／右9px |
| 造型册0／1单品 | Web 等比缩图，没有原生整面填充、单品叠层和渐隐 | 恢复396.63/367舞台，主图下延92px、底部渐隐与左下单品 |
| 造型册文字 | 标题18px、缺少来源标签与原生图标 | 恢复25px标题、11px天气／来源、12px/18px正文及来源优先级 |
| 发现灵感 | 图片固定3:4且无摘要；规则网格不等同原生瀑布流 | 按封面宽高比显示，无尺寸回退正方形；双列按较短列放置，列距10px／行距12px；13px标题、11px摘要 |
| 创建／个人菜单 | 关闭及箭头使用文本字符，字形和对齐不稳定 | 复用原生关闭、创建箭头及个人中心箭头资源 |
| 衣橱／个人中心主体 | 核对前轮比例、行高、资源及布局 | 本轮未发现需再次替换的主背景资源；未接入的二级业务依然不是完成态 |
