# 爱搭衣橱App直连Agent组件与原版签到

日期：2026-11-03。入口：`/app/?design=yijian`。范围仅Web App；未修改iOS源文件。

## 页面组织

爱搭衣橱版进入Agent时不设置iframe URL，直接挂载当前项目的对话、城市、天气、历史、角色、偏好、手记、上传、试穿形象及记录组件。保留既有业务控制器和固定接口，避免重新实现对话并发、账号归属、照片确认与费用确认。爱搭衣橱App原版`/app/`仍保留既有iframe集成。

独立适配层：`closet-app/agent-integration.js`；爱搭衣橱覆盖样式：`agent-yijian.css`。主体使用爱搭衣橱三配色变量、纸面卡片与宋体标题。模块样式在`@scope (#yijian-agent-root)`内，动态创建的弹层移入同一组件根，不影响首页或个人中心。

`python3 scripts/build_inline_agent.py`从正式Agent模板和样式生成`agent-fragment.html`／`agent-scoped.css`。修改正式模板或对应样式后应重新运行。它们是可重建的静态页面资源，不含账号、凭证或用户图片。控制器仍直接复用正式`/static/*.js`，未复制业务状态机。

## 业务与状态

- 聊天与进度：沿用chat/stream、runs、conversations及原响应渲染；保留账号隔离、重试与版本控制。
- 历史恢复、城市与天气、角色及偏好保存、手记修订冲突，继续使用原业务接口。
- 登录直接使用既有mobile-login接口；在原提交处理器上增加手机号／验证码两步展示。未新增短信发送或第三方授权服务。
- 衣物／本人照片：本页选图预览，明确确认后才上传。人物生成与试穿仍通过报价及独立确认，未绕过积分确认。
- 全部弹层与消息在同一文档；Escape先关闭内层弹窗，不能同时把App页面退回。
- 关闭Agent后仍可在个人中心显示message。登录和退出同步App缓存及详情状态，迟到响应继续遵守原控制器的账号归属。

## 原版App签到，爱搭衣橱外观

替代此App此前“对话后10体验积分”的方案：无需先聊天，奖励按服务端配置。独立Agent `/`、`/mobile/`原有体验签到保留，不把两者混为同一积分域。

| 本地固定接口 | 既有App接口 | 行为 |
| --- | --- | --- |
| GET /stylist-api/app/checkin | GET /api/check_in/today、/api/check_in/recent、/api/app_config/config_check | 今日状态、累计天数、本周记录、每日奖励配置 |
| POST /stylist-api/app/checkin | POST /api/check_in | 用户明确点击立即签到，由原服务决定发放与幂等 |

实现：`closet-app/checkin-direct.js`，仅由爱搭衣橱适配器加载。不是新的本地积分账本。进入只读取，不自动领取；同一请求期间按钮禁用；granted=false不冒充新发放。未知结果要求先刷新状态，不自动重放领取。配置缺失显示“—”，不回退写死10／20。已签到时数值标为每日签到积分，不把当前配置冒称为历史实际到账数额。时间、日期、签到天数和规则以服务端为准。

首页小笺新增每日签到入口，对话天气栏也保留入口。展示原App本周七天进度，取消原演示月历和聊天解锁条件。

### 聊天入口登录要求

未登录点击首页和伙伴聊聊，进入同页登录表单；取消不发送chat请求。已有登录态直接进入聊天，发送仍由原控制器及服务端校验，过期提示重新登录。登录完成不自动发送消息。

## 首页原地操作与对话页精简（2026-11-03）

登录、签到、历史列表、上传、试穿形象、生成记录、角色设置、偏好与手记，在来源页面直接弹出，不先导航到Agent。组件根可以在页面外独立承载弹层，保持原页URL及上下文；真正聊天或选择某段历史后才进入对话页。未登录点聊天先在首页登录，成功后再进入聊天。

对话页移除组件内header及weather-toolbar，仅保留App外层导航；右上角账号改为历史对话。隐藏控件仍供业务控制器调用，不影响城市引导卡。生成记录移动到journey-entry，与上传及试穿形象并列；保存触发器引用，避免欢迎区被回复替换后，其他页面的记录入口失效。

签到重新采用日常小笺文案、伙伴署名、奖励与累计天数两列、七天圆角记录及领取操作。保持真实签到规则，无聊天前置条件。数值不写死，错误及未知回执仍以明确message说明，不让情感文案掩盖实际状态。

最新浏览器模拟：320×780、393×852、844×390，验证来源页URL不变、历史选择后进入聊天、SSE消息、对话页顶部精简、签到显式领取及个人中心弹层。另检查游客点聊天停留首页登录、未选角色不显示签到头像。截图`var/yijian-home-checkin-redesign.png`是23积分模拟配置，不是真实奖励。

## 我的数字分身卡片（最新规则）

用户后续明确identity代表本人数字分身，替代此前账号个人卡方案。卡片放在收藏你的小事下方，固定标题「我的数字分身」，不将账号昵称或小主人等称谓作为标题，不借用账号头像或助理立绘。只读GET /stylist-api/twins的custom_twin，系统人物不作为本人分身。未创建、已创建、处理中及未知状态分别表达；未登录不给出已经创建或未创建的假定。创建入口在原页面预览本人照片；性别尚未确定时先使用原形象设置流程，费用确认沿用既有业务。

模块：closet-app/own-twin.js。账号变化清除旧照片与状态，迟到响应丢弃；查询失败展示暂未读取，不伪装为空。已使用模拟账号昵称小主人、不同账号头像和有／无custom_twin验证可见文案及照片来源，并检查位置与创建入口不导航Agent。未真实读取或上传本人照片。
