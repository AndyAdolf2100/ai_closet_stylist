## 陪伴文案

主旨是让界面像一个认真回应用户的伙伴，避免客服套话、技术回执口吻和虚构亲密关系。导航、操作名、费用、积分、订单状态、错误原因保持明确，不用陪伴话术掩盖限制。

| 场景 | 调整后示例 |
|---|---|
| 我的日常 | 你的喜欢，值得在这里留一页。 |
| 陪伴小笺 | 今天，也想听听你的想法。 |
| 生成空态 | 新的模样，还等你来试。 |
| 搭配空态 | 这一页，留给喜欢的搭配。 |
| 消息空态 | 这里，还没有新的来信。 |
| 衣橱空态 | 先收进一件喜欢的衣服吧。 |
| 反馈 | 有什么想法，想说给我们听？ |
| 反馈收到 | 反馈已收到。谢谢你愿意把想法告诉我们。 |
| 创建数字分身 | 留下一张自己的照片，让喜欢的穿搭有你的模样。 |
| 设置 | 怎样称呼、怎样相处，都听你的。 |
| 登录 | 很高兴，在这里遇见你。 |
| 历史空态 | 第一句话，还等你来写。想聊什么，都可以从今天开始。 |

已自行核读：未假设用户孤独、委屈或关系状态；未使用占有／排他／催促每日回访；未将生成中写成已完成、订单为空写成读取失败，或承诺尚未实现的保存／购买。原600条按角色的首页文案继续沿用，不用排列组合替代。

## 素材与实现

使用内置 image_gen 生成一张四场景透明图集：衣橱、手帐、信件、订单。1254×1254 RGBA，alpha范围0～255。采用CSS四象限裁切，不加工用户图片，也不把插画冒充实际衣物。

素材：[empty-stationery-v1.png](../stylist/static/closet-app/assets/empty-stationery-v1.png)。完整提示词：[empty-stationery-v1.prompt.txt](../stylist/static/closet-app/assets/empty-stationery-v1.prompt.txt)。

布局集中在 `native-polish.css`，App专用弹窗在 `agent-yijian.css`；`empty-art.js`复用插画，`list-refresh.js`处理只读下拉更新、触摸取消和键盘更新。不修改付费、上传、订单或角色模型的业务逻辑。
