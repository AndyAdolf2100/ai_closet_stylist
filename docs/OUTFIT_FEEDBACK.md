# 搭配评价与风格参考（T17）

2026-11-04：用户授权在Stylist完成搭配后，通过点赞调整后续风格喜好。本地实现，未部署；未执行真实文字模型或收费图片验收。

## 当前行为

- App内嵌与独立Agent共用搭配卡：纸笺式「穿搭回音」，宋体标题、细线、主题色心形与轻风图标；「有点心动／再找找感觉」双选项（无障碍名仍为喜欢这套／不喜欢这套）及撤回评价。保存成功才更新状态；失败保留原评价，可重试。历史回显原评价，切换账号丢弃迟到响应。
- 仅已保存且delivery=outfit、非待确认的版本可评价，账号／对话／版本／方案构成唯一键。重复提交替换同一条证据；改选、撤回立即改变后续请求可读证据，不改写原搭配或占用聊天版本。
- 点赞只引用该方案明确的style_name，不从标题、单品或理由猜测风格，更不推断颜色、材质、身材或禁忌。没有风格标签仍可评价，但不会产生风格推断。
- 同一账号、穿衣性别相符、本人方案最近100条点赞中，同一个风格按独立对话版本计数；同一版本多方案相同风格不重复增加。最多五个风格，每个权重0.1～0.3，第三个独立版本后封顶。它是提示词软参考，不是算法精确概率或模型训练。
- 点踩移除该条点赞的正向贡献，不推断长期负面偏好，也不自动重新搭配。用户可继续在对话中明确修改原因。
- 风格参考仅进入造型与修复的outfit_feedback_styles，不写Task、不自动生成手记。当前要求、显式手记、性别、天气、禁穿与冻结条件优先；不能放宽候选安全校验。
- 手记enabled=false或plan.use_profile_preferences=false时不使用评价参考；纯天气／闲聊和target_description非空的其他对象不使用。不会修改账号保存的风格设置。已进行中的模型请求不因之后撤回而重跑；新造型请求读取当前记录。
- 评价端点仅认证和本项目数据库写入，不查商品、不调用文字／图片模型，不触发试穿或积分操作。原衣橱与旧Agent数据域不修改。

## API

`GET /stylist-api/conversations/{conversation_id}/feedback?version=1&look_index=0`

`PUT /stylist-api/conversations/{conversation_id}/feedback`

均须Bearer登录身份。PUT正文：`{"version":1,"look_index":0,"vote":"like"}`，vote支持like、dislike、null（撤回）；GET返回`{"vote":"like"}`。PUT支持可选assistant_persona（既有六人格ID），返回`{"vote":"like","message":"这份喜欢收到了。下次选款，我会多留意这样的风格。"}`。仅保存成功后给出当前人格回音；空风格／他人方案／暂停参考仅确认评价，不承诺下次参考；点踩自然邀请表达想改之处，不自动发送修改请求。服务端从原始已保存搭配读取风格、性别及对象，客户端不能提交推断属性。未归属账号返回404，非完成方案或无效索引返回422。

独立状态表stylist_outfit_feedback，SQLite／PostgreSQL通用schema与MySQL独立schema均已维护；未验证远端数据库迁移或部署。

## 乙游呈现与Agent表达（2026-11-04后续）

本地已实现。页面将技术说明收进实现文档，正文仅保留自然问句、两种选择及助理回音；服务端按六人格生成成功回执，失败不伪装成功，原选择保留。主题色使用App的可读文字强调色，黄色系统主题不直接用亮黄作小字；无位移动画，减少动态效果时取消颜色过渡。44px以上点击区、键盘焦点与读屏状态保留。撤回只清除该次评价，不声称抹去聊天历史。

Agent造型提示词同步：点赞软参考不报算法权重和次数、不宣称一直最爱，不以旧点赞反驳用户新要求，不讨好索赞或把评价当亲密度，不在正文重复页面问句。此部分为提示词及模拟输入证据，未执行真实模型人设评分。

本轮106项Python定向（评价／手记／六人格）、170项前端回归通过；新增前端覆盖成功前不选中、纠正撤回、失败保留与迟到账号响应。App三主题×320／393／1440px及减少动态效果、独立Agent三尺寸Chrome模拟通过；未重复运行全量Python，上方945／85为前一轮基线结果。

## 保存与评价的不可用提示（2026-11-12）

保存穿搭复用owned_look校验；本轮仅细化后端message，原feedback_not_available／HTTP 422和合法历史搭配快照规则保留，不修改iOS。iOS会展示后端message，H5共用Message样式。文案优先说清原因和下一步，保持自然语气，不用陪伴式口号代替原因。

| 保存失败场景 | 当前提示 |
|---|---|
| 搭配仍待确认 | 这次搭配还在等待确认，暂时无法保存。请先完成确认，再保存穿搭。 |
| 所选消息中无对应搭配／序号不匹配 | 这条消息里没有找到你选中的那套搭配。请重新打开对应卡片后再保存。 |
| 单品上下文 | 这张卡片是单品，不是一套搭配，暂时不能保存。先用它搭一套，再保存吧。 |
| 穿搭参考／concept | 这条消息仍属于穿搭参考，暂不支持保存。请让助理生成一套搭配后再保存。 |
| 需求沟通／clarification | 这条消息还在沟通搭配需求，尚未生成搭配结果。请先完成搭配，再保存穿搭。 |

评价接口使用对应评价措辞，不误提示保存。历史版本本身不是保存失败条件；不把这些提示套到合法历史搭配上，也不放开未确认或单品记录的保存资格。27项相关模拟回归通过，包含错误码、无写入、HTTP响应文案及旧版本原单品引用。H5正式入口的模拟Message系统黄对照与三主题三尺寸检查通过；仅H5截图，不冒充iOS真机验证。截图及前后记录见本地UI_CHANGELOG的UI-004。
