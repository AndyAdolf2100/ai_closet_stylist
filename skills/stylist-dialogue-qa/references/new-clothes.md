# 邂逅新衣专项

适用于「邂逅新衣」开关、系统参考款、缺衣双入口、对应对话与回归。先核对项目AGENTS.md的PRD-03和 [当前设计与证据](../../../docs/NEW_CLOTHES.md)，不要恢复历史的系统来源全面暂停或缺衣不允许邀请规则。

## 应验行为

当前界面为「我的衣橱／✧ 邂逅新衣」双选项，替代勾选框／滑动开关；内部仍使用new_clothes布尔字段。检查点击及原生方向键选择、互斥状态、自动同步、历史恢复、退出复位和忙碌时两项禁用，三色手机／PC均位于输入框外上方靠左，无外框／填色块，选中项主题色文字及短下划线；视觉行高32px、距输入框8px，保留可见焦点及44px点击区域。

| 入口／上下文 | 判据 |
| --- | --- |
| 开关默认关闭→手动开启→发送搭配 | 手动开启显示当前六人格功能message，说明已有衣物＋衣橱外参考款；开启本身不发请求，发送后允许个人＋系统；返回真实候选来源，不能只检查task.source |
| 「我想尝试新的搭配，并且是我衣橱里面没有的」 | 自动勾选，按当前六人格通过message提示后继续同一工作流，不多一道确认；流式与最终回执不能重复通知 |
| 已开启搭配→连续追问→关闭／只用已有衣物 | 会话中保留状态；关闭后停止系统检索；旧source或模型source不能绕过；新对话默认关闭 |
| 部分／空个人候选 | 回复末尾添加衣物／开启邂逅新衣双入口；出现卡片不代表自动查系统、打开选图、上传或收费；已开启不重复邀请开启 |
| 查询失败 | 不将故障说成缺衣，不显示误导性缺衣卡 |
| 新鲜感、旧衣新搭、否定、引用、举例、纯文字 | 不误自动开启／查询；「只有文字」不被新衣措辞覆盖 |
| 系统搭配→关闭→只换鞋，其余冻结 | 不能悄悄删除或替换冻结系统单品；冲突时拒绝并保留原版本 |
| 缺衣卡→换号／换会话／版本更新／卡片移除 | 旧卡不能继续操作；忙碌状态防重复提交，草稿和未使用上传锚点保留 |
| 系统图片及组合图 | 来源标注参考款、未确认拥有；只读图片入口须校验本账号已保存的选中商品；相同ID不同来源不串缓存，不写入个人衣橱 |

检查模型提取、服务调用、最终Reply及前端四层：new_clothes、new_clothes_auto_enabled、new_clothes_notice、wardrobe_gap、真实items.source及工具轨迹。上传仍须预览后确认，试穿仍须独立积分确认。禁穿、性别、天气与预算不因开启放宽，不编造购买链接或已拥有状态。

## 仅本功能的执行入口

从项目根目录执行，均不调用真实模型／业务写入：

```sh
.venv/bin/pytest -q tests/test_new_clothes.py tests/test_catalog_retrieval.py
NODE_PATH="$PWD/var/ui-check/node_modules" node --test tests/new_clothes.test.cjs
NODE_PATH=/path/to/node_modules node scripts/check_new_clothes.cjs
```

浏览器脚本依赖playwright与本机Chrome，访问本地8466静态页；/stylist-api/全部用合成响应，不能改成真实账号测试。运行前定位已有playwright模块路径；报告实际使用路径和结果，不将示例路径当已安装。覆盖1440／390／320／844px、三色、双入口续接、草稿、自动提示去重、退出清理与布局；截图在var/new-clothes-ui，不提交。

不因只测本功能而运行全量或追加无关用例。报告本轮命令、通过／失败／跳过及模拟边界，历史次数只保留为旧证据。

## 真实语义与后续边界

Python专项中的Model／Catalog是合成夹具，浏览器也使用合成流，不能称为真实模型识别、人设自然度、系统服务可用性或收费试穿验收。当前evaluate_personas尚未接入本功能的专用系统库适配器和场景，不能直接声称--list或其他真实对话套件已覆盖此功能。需要真实文字验收时，先补合成系统商品适配器、开关请求快照及上述多轮场景，核对清单；只有明确授权真实文字费用后再显式--live，仍不使用真实账号、不执行收费图像。

## 系统召回集成验收

系统检索现接固定签名VikingDB系统文档，配置复用原Agent legacy profile；无配置才兼容MCP。按品类8／8／16阶段扩大软检索，硬性别／类别／禁穿不得放宽。检查业务product_id而非chunk_id、Server详情重读、标题／类别与KB／Server槽位冲突剔除，不覆写原标签；满50件列表不能因占位total=1提前停止。个人候选充足时仍保留显式新衣的系统窗口，单类失败不丢其他结果，回退成功不重复显示全盘失败提示。Reply.retrieval_diagnostics和真实items来源须相互吻合，不能只核对开关。

tests/test_catalog_retrieval.py覆盖签名／身份边界、系统文档隔离、扩大检索、冻结相关基础流程、分类冲突、限页回退、来源窗口和用户原句含多余i的选中单品。独立probe_catalog_readonly需要显式--live-readonly，只证明真实系统知识库元数据，不调用LLM、不复现真实账号Server重读或收费图像；按用户指定范围执行，不能把模拟Model的实际items当真实模型选款。

手动功能message另验：六人格固定说明、重复点已选项／切回个人不弹、关闭后再开启可再解释；历史恢复／程序同步静默。缺衣卡点击也说明，但不与意图自动开启的message重复。仅改前端提示时运行tests/new_clothes.test.cjs及对应浏览器脚本即可，不默认扩为后端全量或真实文字费用测试。
