# 衣衣全身设定 · v1

由内置 imagegen 基于项目现有角色图生成，非用户照片。四张图均为 1536×1024 PNG，上排为全身正面、侧面、背面，下排为睁眼、半闭、闭眼的面部参考。

- `yiyi-female-fullbody-v1.png`：正常比例女助理，脸和发型参考首页女版，服装参考 Q 版。
- `yiyi-male-fullbody-v1.png`：正常比例男助理，沿用首页脸、发型和原有服装配色。
- `yiyi-female-chibi-v1.png` / `yiyi-male-chibi-v1.png`：Q 版正侧背与眨眼参考。

女版统一为米白衬衫、鼠尾草绿无袖马甲、焦糖色半裙、棕色腰带与乐福鞋；保留棕色短卷发、绿色花朵发夹和金色耳饰。男版为米白衬衫、藏蓝开衫、浅褐长裤、棕色腰带与乐福鞋，保留左手腕表。

这些是角色设定图，不直接用作页面动画。页面女版首页使用 `../yiyi-female-window-blink-v4.webp`，保持原窗边姿势，只将长袖开衫改为马甲加衬衫；天气男版使用 `../yiyi-male-weather-blink-v6.webp`，让头肩在每格中占据与女版接近的比例。
