# 首页眼部眨眼精灵图 v2

2026-11-02，built-in image_gen重新生成6张1536×1024、3列2行精灵图，参考v1同角色首页图，保留场景与人物。完整实际提示词见[prompts.json](prompts.json)。v1原稿保留，对话／message／天气静态头像仍使用v1。

用户反馈v1整帧动画抖动，本版以第一格作为固定底图，仅`::after`播放第一行睁眼／半闭眼／闭眼帧。双眼分别使用椭圆渐隐遮罩，另以眼部范围clip-path限制绘制；背景、身体、嘴、头发不参与帧切换。每角色眼部坐标记录于`companion-characters.js`的`blinkEyes`，按容器比例缩放。系统减少动态效果时移除眼部叠层、仅显示睁眼底图。

验证：25项前端回归通过；Chromium六角色各截取睁眼／半闭眼／闭眼状态，检查背景与人物内容区在眼睛外的像素差异为0。像素比较排除圆角边缘的浏览器抗锯齿差异，不宣称整个截图逐像素一致。180px截图检查及桌面／390px闭眼预览目视通过；手机真机未验。证据在本机`var/eye-only-v2/`，不纳入提交。
