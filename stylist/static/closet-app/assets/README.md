# iOS 设计素材复用

来源：AICloset iOS 工作区的已存在 App 设计资源。按用户要求复用于 Web 外壳。

`manifest.json` 列出每份资源相对于 iOS 仓库 `AICloset/` 的来源路径、复制后的文件名和 SHA-256。选择已有最高倍率资源，不缩放源文件；浏览器按逻辑尺寸显示。SVG 保持矢量格式。未包含用户上传照片、账号图片或凭证。
