两类会员，三种账号状态。

按当前 iOS 代码，会员身份分为 VIP、SVIP 两类；加上未开通会员的普通账号，页面共需处理三种身份状态。月卡、年卡是套餐周期，不是新增会员等级。

普通账号

尚未开通会员

不展示皇冠或会员光效，保留账号头像、昵称和实际积分。

依据：is_vip = false
VIP会员

VIP

浅香槟金徽章与柔光。持有列表的模型注释将这一类标为“VIP永久”。

个人页：is_vip = true 且 vip_type = 5
SVIP会员

SVIP

深色金边徽章与更明显的柔光。商品模型中有月、年周期；是否自动续费以 StoreKit 商品为准。

个人页：is_vip = true 且 vip_type ≠ 5

字段不要混用

字段 / 场景代码规则含义
vip_info.is_viptrue / false当前是否为有效会员；不是具体等级。
vip_info.vip_type5 → VIP；其余有效会员 → SVIP当前个人页徽章判断，不代表服务端所有商品枚举。
vip_info.vip_list[].type1 → VIP；2 → SVIP持有权益列表，独立的类型编号；代码可逐项展示两类的有效期。
商品 VipProduct.vipType注释：2 → 月；3 → 年套餐周期线索。实际在售列表、名称、天数由商品接口提供。
StoreKit product.type自动续费 / 其他商品类型自动续费属性不构成第三类会员。
当前能确认的是会员分类，不是在售套餐总数。

本页核对本地 iOS 源码，没有查询当前商品接口或 App Store。价格、赠送积分、详细权益和实际在售套餐数量均不据历史文案推断。未读取会员信息时，页面应显示待同步，不能直接判为普通账号。
