Agent 埋点接口与字段对照

依据用户指定iOS分支 dev_2.0.0 / 48e77c24，核对EventTrackDefine.swift、AppAnalyticsManager.swift及实际调用。只新增必要Agent语义，不把含义不同的旧事件硬套过来。当前H5仅彩色控制台，未接SDK、远端采集或入库，iOS／Android本轮未改。

调用方式与字段风格

// H5：进入Agent后可试验，仍只打印控制台
AgentTracking.track('ClickAgentBtn', { btn_type: 'history' });

// iOS后续接入示意：复用现有AppAnalyticsUtil封装
AppAnalyticsUtil.track(eventName: "ClickAgentBtn", properties: [
  "page_name": "Agent",
  "source_page": "Outfit",
  "surface": "ios_agent",
  "btn_type": "history"
])

ClickAgentBtn和Agent页面值是新增约定，不是iOS已经存在的事件。page_params原生由现有公共属性机制补充，需补Agent VC映射，避免为空；H5自动补同值用于对照。原生已有的新用户／次留、设备等SDK公共属性继续由原生负责，H5不虚构这些信息。

eventName是调用参数，properties是业务字段；不是新HTTP接口，也不是声称数据库已有同名表。当前无实际存储；后续上报再按这些类型注册事件字段。

风格：事件PascalCase（PageView、Click…、Agent…），字段snake_case。默认11类业务事件，3类技术事件仅 AgentTracking.setDebug(true) 输出。关闭全部日志用 AgentTracking.setEnabled(false)。控制台筛选Agent。

复用、必要新增与删除

处理内容原因
直接复用PageView；page_name、source_page、page_params、btn_type、waiting_time、outfit_count、is_depleted与指定分支的既有命名、类型、单位一致；来源值沿用Outfit／Closet／Personal_center。
必要新增ClickAgentBtn和Agent请求／回应事件；surface、palette及本页请求关联等字段iOS该分支没有聊天发送／首段正文等同义定义，不能冒用旧业务成功事件。
已替换elapsed_ms→waiting_time（毫秒转秒）；view_ms→stay_time（秒）；look_count→outfit_count；action→btn_type内部耗时可由适配器转换，控制台最终字段按本页规范，旧新字段不重复输出。
已删除／降噪不传event_key、seq，不再保留内部别名；三个技术事件默认关闭；无意义的点击附加参数不传eventName为唯一事件名称；event_id保留用户确认的可读字符串。每次点击不重复打印has_new_content=false。

不复用：ClickAddPhotoItemBtn／ClickTakePhotoItemBtn是单品入柜，聊天照片不是入柜；ClickTryOnViewBtn是查看试穿，Agent按钮打开报价并非查看结果；ClickTryonHistory仅试穿记录，而Agent生成记录还含其他任务。PointsConsumption、PaySuccess、CreateModelSuccess只在相应真实边界使用，本次不新增或伪造。AgentResult也不冒充AIOutfitResultView。

iOS 开发中的接入方式

iOS功能仍在开发。本页是埋点接口与字段合同，不要求代码文件、方法或UI结构与H5一致。iOS同学按真实业务流程定位接入点，复用现有AppAnalyticsUtil.track(eventName:properties:)。

  • 先依据每个事件的触发条件接线，再根据当前页面结构决定放在哪个方法；H5控件选择器和截图仅帮助理解功能。
  • 已完成的功能可以先接。尚未支持的首段正文、新内容提示等交互先不触发对应事件，不用计时器或其他事件模拟。
  • PageView与已有BaseViewController页面曝光去重，同一次实际显示只记录一次；原生page_params由现有公共属性机制提供，Agent页面映射需要补齐。
  • 首次正文与最终结果按实际可见边界记录；历史重放不算新回复，重连沿用同一attempt，每轮结果与失败不得重复统计。
  • 先核对事件名、字段类型、单位、枚举和去重，再在调试包验证日志；SDK后台接收和字段入库是后续单独验收，不由H5控制台截图代替。

因此可以拿本页开展iOS埋点开发，无需等全部页面完成；本页不声称原生已经接好。

字段：名字、类型、单位、什么时候传

字段类型依据规则
page_nameStringiOS已有页面曝光PageView必须，Agent取Agent（新增页面值）
page_paramsStringiOS动态公共属性由当前VC映射提供，Agent取Agent；H5控制台模拟公共属性，不另记页面事件
source_pageStringiOS已有本次进入Agent的来源页面，Outfit／Closet／Personal_center，未知空串；沿用大小写
btn_typeStringiOS已有字段，Agent新增枚举仅ClickAgentBtn；下方28类固定操作，避免为每个按钮新增事件
waiting_timeNumberiOS已有等待时长，单位秒，最多三位小数；首段／结果／失败／中断从发送校验通过开始计时，不是纯模型耗时
outfit_countNumber（整数）iOS已有仅AgentResult，结果包含的搭配方案数，未返回搭配则0
is_depletedBooleaniOS已有仅AgentSendBlocked，固定true；表示预检查余额不足，不是扣分成功或卡片曝光
surfaceStringAgent新增h5_agent／ios_agent／android_agent；当前仅H5，浏览器H5始终h5_agent
paletteStringAgent新增system／male／female，当前界面配色，不是用户性别
event_idStringAgent新增，本地识别例如AgentResult_000012，eventName＋本页序号；刷新重置，不作跨端唯一ID
attemptNumber（整数）Agent新增，本页关联一次发送尝试编号，本页递增，重连沿用，不是会话ID或服务端任务ID
stay_timeNumberAgent新增仅AgentLeave，本次进入至离开的秒数，非活跃时长；不混用waiting_time
text_lengthNumber（整数）Agent新增仅AgentSend，Unicode字符数，不传原文
has_imageBooleanAgent新增仅AgentSend，是否带本轮图片，不传文件名／URL／内容
new_clothesBooleanAgent新增仅AgentSend，是否开启邂逅新衣
resumingBooleanAgent新增仅AgentSend，是否恢复此前待处理请求
retry_countNumber（整数）Agent新增结果／失败／中断汇总重连次数；调试请求／重连事件也可传
deliveryStringAgent新增仅AgentResult：advice／outfit／concept／clarification
error_kindStringAgent新增仅AgentError：auth／network／model／other，不传原始异常
stageStringAgent新增，调试connecting／understanding／weather／wardrobe／styling／checking／new_clothes，每轮每阶段一次
outcomeStringAgent新增仅AgentAttachment：selected／ready／failed／removed；ready仅代表本地预览就绪
sourceStringAgent新增仅AgentAttachment selected：photo／camera；不同于source_page
choiceStringAgent新增仅评价点击：like／dislike／undo，只记点击意图
has_new_contentBooleanAgent新增仅回到底部点击；true表示用户点了有新内容提示

只允许上述固定枚举、布尔值及有限数字；未知字段丢弃。无用户／会话ID、凭证、手机号、原文、原始异常、图片内容或URL。event_id和attempt不能用来跨刷新、跨设备关联用户。

验收与范围

H5 Agent可见期间记录操作；发送的结束事件可以在离开后完成。历史回放不重复记新生成，重连不新增AgentSend，阶段每轮去重；成功后历史刷新失败不再误记AgentError。AgentSendBlocked只表示余额检查拦截，不表示不足卡片曝光。

三主题×三视口模拟验证生命周期、隐私、命名与调试开关；失败另有模拟检查。截图是合成资料，不是线上接口成功证据。尚未验证原生接线、SDK接收或数据库入库。两类部署前仍需确认截图是否转OSS及当前可用token。
